Перенёс авторизацию из вашего FIZMA.zip: форму, терминальную колонку, зелёную палитру, эффекты кнопок, оригинальные шрифты Geist и подсветку курсора 400→500 px. Формы подключены к существующей регистрации игры.

Также реализованы HTTPS-приглашения, исправлены диалоги с моделью, пиксельные подписи персонажей и пересечения геометрии дверей. Админ-панель доработана для всех семи отсеков. Бинарники пересобраны.

КАК ПОДКЛЮЧИТЬ ДРУГА ПО HTTPS

На компьютере ведущего откройте терминал:

cd /Users/a1/Desktop/LastCrew_FlightDeck

Один раз установите коннектор на хосте:

go run . --install-tunnel

Запустите игру:

OLLAMA_ENABLED=true go run . --share

1. Дождитесь сообщения HTTPS invitation ready.
2. Откройте напечатанную HTTPS-ссылку, войдите и создайте экспедицию.
3. Нажмите «Пригласить друзей», отправьте ссылку с кодом.
4. Друг открывает её в браузере, регистрирует свой аккаунт и нажимает «Присоединиться». Устанавливать ему ничего не нужно.
5. Все выбирают роли и нажимают «Я готов»; ведущий запускает миссию.

Терминал ведущего должен оставаться открытым. Этот режим использует Cloudflare Quick Tunnel: интернет нужен обоим, ссылка меняется после перезапуска.
Официальное описание: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

Для обычной LAN без интернета сохранён запуск:

go run .

Друг подключается по адресу http://IP-хоста:8080.
HTTPS в изолированной LAN требует заранее настроенного доверенного сертификата.

Можно запускать уже собранный файл:

./lastcrew --install-tunnel
./lastcrew --share

КАК РАЗГОВАРИВАТЬ С ИИ

Ollama нужна только ведущему.

1. Откройте приложение Ollama либо выполните в отдельном терминале:

ollama serve

2. Проверьте список моделей:

ollama list

Если нужной модели нет:

ollama pull qwen3:4b-instruct-2507-q4_K_M

3. В миссии откройте «Связь» → «Наставник» → «Проверить ИИ».
4. Выберите персонажа, напишите вопрос и нажмите Enter. Shift+Enter — новая строка. Рядом с персонажем разговор открывается через E.

Проверка настоящей генерации из папки проекта:

go run ./cmd/check-agents -agent savinykh -question "Привет!"

Ожидается mode: "model". Резервный ответ теперь явно подписан. Дополнительная настройка MCP не требуется.

АДМИН-ПАНЕЛЬ И УПРАВЛЕНИЕ

Админ-панель открывается кнопкой «Администратор» у владельца экспедиции.
Движение: «Исследовать», WASD, мышь.
E — взаимодействие.
Esc — освободить курсор.
