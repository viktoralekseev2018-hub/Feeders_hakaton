# Готовая версия для запуска

Это компактная копия LastCrew Flight Deck. Новый фронтенд, серверные бинарники Windows/Linux/macOS, игровые ассеты и знания полностью сохранены.

1. Полностью распакуйте ZIP.
2. Windows: откройте Start.bat. Linux: bash Start.sh. macOS Apple Silicon: Start.command.
3. Откройте http://localhost:8080.

Не удаляйте папку web: скрипты запуска подключают из неё обновлённый интерфейс. Серверные бинарники сохранены из исходного проекта и не перекомпилированы.

В этой компактной копии отсутствует только корневой каталог vendor — зависимости Go для пересборки сервера. Для запуска он не требуется. Если захотите пересобрать сервер без интернета, перенесите vendor из вашего исходного LastCrew.zip в эту папку рядом с go.mod.

Исходники изменений, инструкции и результаты проверок включены. Подробный отчёт: FRONTEND_REPORT.md. Заявления исходной документации о включённом vendor относятся к полной версии, а не к этому компактному архиву.
