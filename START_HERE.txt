Светлый интерьер: 7 отсеков, 12 дверей. Подробности: docs/INTERIOR_UPDATE.md.
Локальные наставники: Ollama + qwen3:4b-instruct-2507-q4_K_M (включено по умолчанию).
После обновления перезапустите сервер и перезагрузите страницу.

Из исходников: откройте терминал в папке проекта и выполните go run .
Собрать один раз: go build -o lastcrew .
Запуск собранного на macOS/Linux: ./lastcrew
Windows: go build -o lastcrew.exe . и затем .\lastcrew.exe
Адрес игры: http://localhost:8080. Остановка: Ctrl+C.
Нужен Go 1.23+; для готового бинарника Go не нужен.
Запускайте из корня: world/ и knowledge/ нужны рядом; сохранения в data/.
MCP уже внутри бинарника. Ollama запускается отдельно (приложение или ollama serve).

Обновление к воскресенью, 1 ноября 2026

1. Сохраните всю папку проекта вместе с web, world, knowledge и bin.
2. macOS Apple Silicon: Start.command. Windows x64: Start.bat. Linux x64: bash Start.sh.
3. Откройте http://localhost:8080.
4. Зарегистрируйтесь, создайте экспедицию, выберите роль → Я готов → Начать миссию.

У владельца в верхней панели: «Администратор».
Вкладки: предметы, вселенная, агенты, клиенты (FPS/ping).
У остальных участников: «Живой мир».

E — взаимодействовать с близким объектом или наставником.
G — положить переносимый контейнер.
WASD — движение в режиме исследования; Esc — освободить указатель.
Просьбы наставнику: «Создай сад», «Добавь ящики», «Добавь маяк», «Открой двери».

Серверные бинарники пересобраны для трёх платформ. Go/npm для запуска не нужны.
Для пересборки исходников требуется Go и его зависимости (vendor здесь не включён).
Инструкции и ограничения проверки: README.md и docs/SUNDAY_UPDATE.md.

Если терминал VS Code/Cursor закрывается с ошибкой /bin/zsh и кодом 127:
Нажмите Cmd+Shift+P → Tasks: Run Task → LastCrew: запустить игру.
Эта задача запускает сервер напрямую, без оболочки zsh.
Либо закройте старый терминал кнопкой корзины и создайте новый: для этой папки
настроен LastCrew Bash без пользовательских стартовых файлов оболочки.
