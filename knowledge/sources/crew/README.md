# Документы и происхождение

Каталог содержит 60 подготовленных документов для Джанибекова, Рязанского и Крикалёва. Файлы `documents.json` и `documents/` — исходные данные для `scripts/build_crew_corpus.py`. Сервер читает сгенерированные `knowledge/{person}.jsonl`.

Список ссылок: [SOURCES.md](SOURCES.md). Запуск, состав, ограничения и проверки: [docs/crew-rag.md](../../../docs/crew-rag.md).

`content_mode=summary` — пересказ своими словами. `public_domain_excerpt` — выбранный извлечённый текст публикации NASA. `relation_to_person=person` означает интервью или материал о человеке; `mission_context` — контекст его полёта; `role_background` — справку других авторов для игровой специальности. Последний тип нельзя выдавать за личную работу или воспоминания космонавта.

`source_text_sha256` относится к использованному извлечению оригинала; `sha256` — к включённому Markdown. Оригинальные HTML/PDF для всех источников не включены: повторную загрузку выполняет отдельный скрипт в локальный каталог. Дата получения не означает актуальность каждой цифры или должности в архивной публикации.
