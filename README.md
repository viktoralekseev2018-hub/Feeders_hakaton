# Feeders Hakaton — Образовательный мир «ХроноГрад VR»

Многопользовательская браузерная 3D/VR платформа на Three.js и Go для автономных локальных сетей (LAN / Wi-Fi без доступа к интернету).

## Структура клиентской части (Зона Разработчика 3)

```
web/
├── index.html                  # Главная страница (Import Map + WebGL Canvas + UI)
├── css/
│   └── style.css               # Стили интерфейса (Glassmorphism, адаптивность)
├── vendor/
│   ├── three.module.js         # Three.js r160 (завендорен оффлайн)
│   ├── PointerLockControls.js  # Управление камерой от первого лица (WASD + мышь)
│   └── GLTFLoader.js           # Загрузчик 3D-моделей
└── src/
    ├── main.js                 # Инициализация Three.js сцены, площади и цикла рендера
    ├── controls/
    │   └── PlayerControls.js   # Движение персонажа, физика, высота взгляда 1.7м
    ├── net/
    │   └── NetworkManager.js   # HTTP-авторизация (cookie) и WebSocket-клиент
    └── ui/
        └── AuthModal.js        # Модальное окно входа и регистрации
```

## Статус реализации: Этап 1 (Каркас)

* [x] Three.js WebGL-рендерер с ACES Filmic Tone Mapping и мягкими тенями.
* [x] Окружение площади ХроноГрада: координатная сетка, освещение, парящий монумент Хронографа.
* [x] Управление FPS: `W`, `A`, `S`, `D`, `Shift` (бег), захват мыши по клику (PointerLock).
* [x] Экран авторизации: переключение «Вход» / «Регистрация», валидация формы.
* [x] Сетевой модуль: HTTP-вызовы `/api/auth/login` и `/api/auth/register` с `credentials: 'include'`, открытие WebSocket на `/ws`.
* [x] HUD оверлей: статус подключения LAN (онлайн/оффлайн), имя игрока, живые координаты $X, Y, Z$.
* [x] Отправка событий перемещения `player.input` с частотой 18 Гц по сетевому контракту ТЗ.
* [x] 100% автономная оффлайн-работа: библиотека Three.js r160 завендорена локально, сборщик не требуется.

## Локальный запуск

Клиентские файлы готовы для прямой раздачи Go-сервером через `go:embed web/*` или встроенный статический сервер:
```bash
# Для быстрого превью можно открыть в браузере или использовать любой локальный HTTP-сервер:
# Например, Go сервер Разработчика 1:
go run cmd/game-server/main.go
```
