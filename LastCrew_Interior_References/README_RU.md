# Интерьер LastCrew: изображения и промпт

В пакете 9 PNG: 8 художественных референсов и 1 схема палубы. Изображения собраны из материалов этой беседы в исходном качестве. Новые изображения для этого архива не генерировались.

## Как использовать

1. Распакуйте ZIP.
2. Перенесите папку `LastCrew_Interior_References` целиком в корень вашего проекта — рядом с `go.mod`, `web` и другими папками. Если проект расположен в `LastCrew_FlightDeck`, итоговый путь будет `LastCrew_FlightDeck/LastCrew_Interior_References/PROMPT_FOR_CODEX_RU.txt`.
3. Для просмотра картинок откройте `VIEW_REFERENCES.html`. Он работает локально без сервера и интернета. Отдельные PNG находятся в `images/`, схема — в `layout/`.
4. В сессии Codex, открытой в корне проекта, вставьте текст из `PASTE_IN_CODEX.txt`. Это обычное сообщение Codex, а не shell-команда. Оно поручит прочитать и выполнить полный промпт.
5. Можно вместо короткого сообщения открыть `PROMPT_FOR_CODEX_RU.txt`, скопировать весь текст и вставить в Codex.

## Содержимое

- `images/` — общий стиль, четыре комнаты, коридоры и двери, окно, закрытые объёмы корабля.
- `layout/` — схема палубы и JSON с координатами ранее доступной версии.
- `PROMPT_FOR_CODEX_RU.txt` — подробное задание по визуальному качеству, ходьбе, дверям, коллизиям, чанкам и проверкам.
- `PASTE_IN_CODEX.txt` — короткое сообщение для запуска задания.
- `REFERENCE_INDEX.md` — назначение каждого изображения.
- `VIEW_REFERENCES.html` — локальная галерея.
- `MANIFEST.json` — точный список PNG, размеры и контрольные суммы.

Промпт предназначен для переделки интерьера текущей игры. Он сохраняет четырёх NPC, отдельных игроков, существующие диалоги и RAG. Изображения задают художественное направление; реализацию и соответствие этому направлению Codex должен проверить в самой игре.

Файл `layout/existing_map.json` и схема относятся к прежнему снимку проекта. Codex должен сверить их со свежими исходниками. На схеме жёлтые пороги и голубое окно показаны как предложения, а не как уже работающие двери.
