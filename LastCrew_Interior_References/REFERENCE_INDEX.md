# Референсы интерьера LastCrew

8 художественных референсов и 1 схема. Все PNG скопированы без изменения из материалов этой беседы. Это целевой образ интерьера, не скриншоты готовой игры.

| Файл | Назначение |
|---|---|
| `images/00_style_reference.png` | **Общий стиль — вариант № 5**. Светлый футуризм: материалы, цвет и плотность технических деталей. |
| `images/01_bridge.png` | **Мостик**. Консоли, рабочие места, окно, стены и потолок. |
| `images/02_reactor.png` | **Реакторный отсек**. Корпус реактора, опоры, трубопроводы и пост инженера. |
| `images/03_greenhouse.png` | **Оранжерея**. Гидропонные столы, растения, полив и рабочая станция. |
| `images/04_cryo.png` | **Криоотсек**. Криокапсулы, остекление, шкафы и медицинские терминалы. |
| `images/05_corridors_doors.png` | **Коридоры и двери**. Закрытые переходы, силовые рамы, дверные створки и подсветка. |
| `images/06_panoramic_window.png` | **Панорамное окно**. Общий вид и детали многослойной рамы; вид на Юпитер и Европу. |
| `images/07_closed_ship.png` | **Закрытые объёмы корабля**. Дополнительный внешний вид для понимания крыши и связей отсеков. |
| `layout/08_deck_plan.png` | **План палубы**. Схема прежней версии проекта; двери и окно показаны как предложения. |

Сначала используйте общий стиль и изображения конкретных комнат. Общий вид закрытых объёмов помогает понять оболочку, а схема — расположение. Актуальные исходники проекта имеют приоритет над снимком старой карты. Люди на концептах служат для масштаба. Различия фона планет и случайные надписи не являются требованиями.
