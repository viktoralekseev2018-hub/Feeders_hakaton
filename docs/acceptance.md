# Проверка интеграции

## Автотесты и один ноутбук

1. `go test ./...`, `go vet ./...`; `-race` при наличии C-компилятора.
2. `go run ./cmd/game-server`; GET /healthz → 200.
3. Создать аккаунт в клиенте. В DevTools: register 201, login 200 (UI вызывает оба),
   WS /ws 101; player.init → player.ready, затем ping/pong. Capabilities=false.
4. В приватном окне без cookie `new WebSocket('ws://' + location.host + '/ws')`
   отклоняется с HTTP 401.
5. После `fetch('/api/auth/logout', {method:'POST'})` сокет закроется примерно за секунду.
6. Перезапустить сервер: старая сессия недействительна, прежний login работает;
   после init загружается тот же player ID и файл состояния.
7. /api/unknown и /missing.js → 404, не HTML с кодом 200. Ctrl+C завершает сервер
   даже с открытой вкладкой и сокетом.

Автотесты используют настоящие HTTP/WS localhost и временные каталоги; данные
разработчика не затрагивают. Fake World проверяет склейку Join/Input/Leave.

## Два ноутбука / готовность каркаса

1. Заранее собрать бинарник. Отключить WAN/интернет, сохранив LAN/Wi-Fi.
2. Хост запускает бинарник; оба открывают http://IPv4-хоста:8080 с разными аккаунтами.
3. Существующая сцена загружается, auth проходит, WS устанавливается, ping/pong работает.
4. Проверить 401 без cookie, сохранение аккаунтов после рестарта, отсутствие CDN.

Нужны реальные устройства: localhost-тесты не подтверждают LAN/firewall. Если
браузер ограничивает PointerLock/камеру на LAN HTTP, Dev 3 проверяет secure context
и настройки браузера отдельно. Каркас не обещает WebXR/аппаратную VR-поддержку.

## Полное задание, последующие этапы

- Игроки видят друг друга; сервер отклоняет невозможные перемещения.
- После перезахода восстанавливается последняя сохранённая сервером позиция.
- Чанки идут по AOI; resident + in-flight ≤10% мира даже при переходе области,
  включая освобождение GPU и браузерных кешей.
- Есть общение игроков и локальные NPC с памятью действий конкретного игрока.
- Все AI-вычисления и ассеты доступны без интернета, учебный сценарий полезен.

Эти пункты пока не закрыты каркасом.
