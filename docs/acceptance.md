# Приёмка выпуска

Актуальная матрица требований, доказательств и ограничений находится в `TEST_REPORT_RELEASE.md`. Старые отчёты переданной сборки сохранены в `docs/reference/previous-release/` и не описывают возможности этого выпуска.

Для локальной проверки выполните Go tests, vet, race detector и smoke-test готового Linux-хоста. На демонстрационных компьютерах отдельно проверьте запуск соответствующего бинарника, аппаратный WebGL, fullscreen, Ollama с настоящими весами и два физических устройства по `docs/LAN_CHECK.md`.
