# Демонстрация на 3–5 минут

**До показа:** заранее запустить нужные бинарники, при необходимости Ollama и уже загруженные веса; проверить адрес LAN, WebGL и наличие свободного порта. Подготовить два различных аккаунта. Не загружать зависимости во время показа.

| Время | Действие | Что видно |
|---|---|---|
| 0:00–0:40 | Показать регистрацию, открыть комнату на втором ноутбуке, выбрать капитана и инженера | Единый стиль FIZMA, код комнаты, роли и готовность |
| 0:40–1:20 | Открыть Савиных у штурвала, спросить инженера об охлаждении | Различающиеся 3D-персонажи, состояние корабля, подпись режима ответа |
| 1:20–2:00 | Инженер открывает ремонт, показывает прогноз и подтверждает | На обоих клиентах O₂56/E25/H70, цикл2; обновлённая задача и состояние |
| 2:00–2:40 | Открыть локальный источник из ответа, затем общий чат | Материал читается без внешнего сайта; обсуждение своей комнаты |
| 2:40–3:30 | Световые часы: роли, два прогноза, v0.6, общий запуск | γ1.25, два участника, сохранённый результат |
| 3:30–4:30 | Перезапустить хост и вернуться с тех же аккаунтов | Та же комната, ресурсы, роли и личная история |
| 4:30–5:00 | Показать кеш и объяснить границы проверки | Реальные байты, резерв загрузок, пик меньше10%; различие модели и справочного режима |

Для расширенного показа продолжить основной квест: реактор → оранжерея → архив → расследование → коллективный финальный манёвр. Тесты полного успеха и неуспеха находятся в `internal/game/rooms_test.go`.
