`ScenarioEngine` — единственный активный движок ресурсов внутри каждой комнаты. `internal/mission` сохранён как библиотека донора; её независимый Service в игровом хосте не запускается. Прогнозы используют копию того же ScenarioEngine.

SQLite хранит аккаунты, игроков и сериализованное состояние приложения. Комната, её receipts и прогресс сохраняются одной записью. Snapshot копирует срезы; UI-представление комнаты не отдаёт изменяемые карты. Блокировки защищают общий доступ, проверка race выполнялась.

Модель получает только личный контекст текущей миссии и разрешённые тексты. Числа рассчитывает сервер. Поиск проходит через отдельный MCP-процесс; при его сбое включается подписанный внутренний поиск. Вызов `_start_experiment` проходит через MCP и внутренний endpoint с одноразовой на запуск capability. Игрок определяется хостом; модель не передаёт ID игрока и адрес сервера.

## Мир и метрика кеша

`world/manifest.json` описывает 287 реальных ресурсов и 24 чанка. В W входят уникальные сериализованные геометрии, материалы, изображения, текстуры и объекты обеих используемых LOD-версий. Не входят vendor, код, знания и файлы, не участвующие в 3D-мире. Фоновая схема и шаблоны аватаров включены. Клиент получает только серверный план, не полный manifest.

C — сумма уникальных ресурсов, удерживаемых для активной области. Незавершённые загрузки резервируются до fetch. При смене области старые объекты удаляются, GPU-ресурсы без оставшихся ссылок освобождаются. Рабочий бюджет 8% оставляет запас до жёстких 10%. Это метрика байтов игровых ресурсов, а не доказательство ограничения JS heap или VRAM до 10% от памяти устройства.

Проверки: `node scripts/verify-world.mjs` проверяет SHA, реальные размеры, парсинг Three.js, координаты четырёх NPC и конечность геометрии. `TestRealWorldBudgetsAcrossAllCells` обходит позиции сеткой. В интерфейсе кнопка «МИР … / 10%» показывает удержание, резерв и пик маршрута.

`world_source/` не встроен в клиент и не раздаёт целиком процедурные модели. Для повторной генерации установите `@napi-rs/canvas` в среде разработки, затем выполните `node scripts/build-world.mjs`. Если пакет не локальный, допустимо указать `CODEX_PRIMARY_RUNTIME_NODE_MODULES` на каталог runtime-зависимостей. Генерация меняет ID ресурсов: поставляйте новый manifest вместе со всеми его файлами и повторите проверки. Для обычной сборки Go готовая папка `world/` уже достаточна.

Устаревшие неиспользуемые классы прежнего UI и фиктивного ChunkCache удалены из активного web-дерева. Исходные пользовательские ZIP не изменялись.
