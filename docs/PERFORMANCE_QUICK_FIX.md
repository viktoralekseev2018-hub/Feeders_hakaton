# Быстрое исправление производительности и текстур

1 ноября 2026. Запуск и управление: [RUN_RU.md](RUN_RU.md).

## Изменения

- Программный растеризатор обрабатывает только участок строки внутри треугольника. Раньше он проверял весь прямоугольник вокруг каждого треугольника, особенно дорого для тонких панелей. Исправлена обработка прозрачных и alpha-tested пикселей.
- NPC за закрытыми переборками продолжают двигаться, но не обновляют части модели. В WebGL видимые экземпляры уплотняются: скрытые жители больше не отправляются на отрисовку с нулевым масштабом. В Canvas их меши скрываются. Цвета формы и возвращение NPC при открытии комнат проверены.
- В существующем пакете мира 70 из 73 текстур загружались без mipmaps. Загрузчик включает mipmaps и анизотропную фильтрацию до 4× с учётом возможностей устройства. Сохранены изображение, UV, переворот экранов и цветовое пространство. Исправление работает с текущими файлами мира без их пересборки. Генератор также сохраняет эти параметры для будущих сборок.
- Лимит Canvas-буфера уменьшен с 960×540 до 640×360 пикселей в сбалансированном режиме; экономный режим — до 480×270. Пропорции окна сохраняются, автоматическое снижение разрешения продолжает работать. Разрешение DOM-интерфейса не уменьшается.
- Экономный режим WebGL отключает динамические тени; сбалансированный включает их обратно. Подсказка в настройках отражает это поведение.

## Замер на текущем Mac

Один и тот же сериализованный план мостика, Node 24.11.0, macOS arm64, два прогревочных и шесть измеряемых кадров. Использован `scripts/benchmark-render.mjs`.

| Условие | До | После |
|---|---:|---:|
| CPU-кадр 1440×900, медиана | 238,09 мс | 120,88 мс |
| Начальный интерактивный бюджет Canvas | 111,37 мс, 911×569 | 53,49 мс, 607×379 |

Полноразмерные кадры имеют **одинаковый SHA-256 всех RGBA-пикселей**. Первый замер показывает ускорение растеризатора при одинаковом качестве; второй включает снижение разрешения. [Исходные результаты](interior-review/performance-quick-fix.json).

Это офлайн-замер CPU, а не игровой FPS или скорость WebGL. В динамической сцене дополнительно работают NPC, сеть и интерфейс. Подключение Browser завершилось ошибкой среды, отдельный Chrome завершился при запуске. Аппаратные тени, внешний вид фильтрации в WebGL и FPS на пользовательском компьютере остаются непроверенными.

## Проверки

- `npm test`: 20 наборов, включая реальные ресурсы мира, их SHA-256, повторный маршрут загрузки, комнаты, двери, движение, NPC и новую проверку всех 73 текстур.
- `node scripts/test-software-lighting.mjs`: реальные пиксели освещения, clipping, глубина, повторы UV, ориентация экранов, прозрачность и alpha test.
- `go test ./web ./internal/app`, `python3 scripts/test-launcher.py ./lastcrew`: проверки launcher и настоящий MCP stdio без записи пользовательских данных.
- Во всех четырёх серверных бинарниках проверено побайтовое присутствие актуальных HTML, CSS и JS, включая новый модуль текстур.
- Сетевой smoke-test `go run ./cmd/smoke-release ./lastcrew` заблокирован средой до старта сервера: `listen tcp 127.0.0.1:0: bind: operation not permitted`. В этом обновлении не подтверждены запуск HTTP-сервера и обмен двух живых WebSocket-клиентов.

`lastcrew` и серверы в `bin/` пересобраны. На macOS проверены команды готового бинарника без TCP; Windows/Linux — перекрёстной сборкой. Проверки не создают рабочую игровую базу; пользовательские аккаунты и сохранения в `data/` не изменялись.

После обновления остановите старый процесс, запустите игру заново и перезагрузите вкладку. Для повтора теста пикселей и бенчмарка нужны Node и зависимость `@napi-rs/canvas` из `package.json`; для обычного запуска они не требуются.
