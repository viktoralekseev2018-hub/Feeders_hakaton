# Проверка двух ноутбуков на месте

1. Распакуйте сборку целиком на хосте. Подключите оба ноутбука к одному Wi-Fi/LAN. Сначала оставьте внешний интернет доступным только для предварительной подготовки, если нужно установить Ollama и веса.
2. Запустите хост, откройте `http://localhost:8080`, зарегистрируйтесь и создайте комнату. Кнопка «Пригласить» показывает адреса сетевых интерфейсов. Выберите адрес сети, общей для ноутбуков, а не VPN или виртуального адаптера.
3. Разрешите входящие подключения приложения в частной сети, если ОС спрашивает. Используемый TCP-порт по умолчанию 8080. Проверьте отсутствие изоляции Wi-Fi-клиентов на точке доступа.
4. Второй игрок открывает `http://IP-хоста:8080`, создаёт собственный аккаунт, вводит код комнаты. Назначьте капитана и инженера, подтвердите готовность, начните миссию.
5. Передвигайтесь, отправьте общее сообщение. Инженер ремонтирует охлаждение: оба должны увидеть O₂=56, E=25, H=70, цикл 2. Повторное нажатие в момент выполнения не должно повторно списывать ресурсы.
6. Откройте источники NPC. В лаборатории один участник — оператор, другой — наблюдатель; оба делают прогноз. При v=0.6 результат γ=1.25. В одиночном просмотре командный зачёт не присваивается.
7. Закройте вкладку второго игрока, затем войдите снова. Роль, прогресс и личный разговор должны восстановиться. Остановите и запустите хост — повторите проверку комнаты и сохранённых ресурсов.
8. Отключите внешний интернет, сохранив локальную сеть. Обновите обе вкладки: сцена, источники, операции и подготовленная локальная модель должны работать без CDN.
9. Отключите Wi-Fi хоста: loopback на хосте должен остаться доступен; удалённый ноутбук должен показать «Нет связи». Восстановите Wi-Fi — клиент переподключается без автоматического повтора операций.
10. На каждом ноутбуке проверьте WebGL, реальную частоту кадров, WASD, фокус чата, Escape и вход/выход fullscreen. При выключенном WebGL совместимый Canvas заметно медленнее и служит резервом.

Эта инструкция — незавершённая физическая приёмка. Автоматические WebSocket-клиенты на одном Linux-хосте её не заменяют.
