## FIZMA и курсор

Перенесены значения из исходных `auth-form.tsx`, `header.tsx`, `cursor-glow.tsx`, `globals.css`, `themes.ts`. Курсор: ореол 400 px, 500 px над интерактивными элементами, размытие 12 px, градиент до 66%; ядро 32 px, прозрачность 0.15, размытие 4 px. Как в исходнике, эффект предназначен для desktop от 1024 px. Он не перехватывает мышь и скрыт во время игры/pointer lock.

Все 11 файлов WOFF2 совпадают по SHA-256 с файлами из архива. Происхождение и лицензия находятся в `web/css/fonts/`. Игра не требует Next.js, React, внешнего CDN или архива FIZMA во время запуска. Архив требуется только тесту прямого сравнения с оригиналом. Не относящиеся к оформлению приватные каталоги архива не перенесены.

Пиксельное сравнение браузерных снимков не выполнено: Browser завершается ошибкой `Importing module "node:process" is not allowed in node_repl`. Перенос подтверждён сравнением исходников/шрифтов и тестами поведения DOM, а не визуальным заявлением о проверенном совпадении каждого пикселя.

## Сеть и ИИ

[Полный гайд ведущего и гостя](NETWORK_AND_AGENTS.md) содержит команды установки, HTTPS, прямой LAN, собственного сертификата, активации Ollama, разговора и диагностики.

`--share` слушает внутренний HTTP только на loopback. Proxy-заголовки учитываются лишь для закреплённого HTTPS-origin и реального локального peer; проверка Origin не отключена. HTTPS-cookie всегда Secure/HttpOnly. Закрытые MCP-действия вынесены на отдельный локальный порт, `/api/internal/*` на публичном обработчике возвращает 404. Остановка коннектора завершает общий запуск с понятной ошибкой. Временный Quick Tunnel требует интернет у хоста и гостей, а постоянный адрес/гарантированная доступность этим режимом не предоставляются.

Отдельный HTTPS без интернета поддерживается с заранее выданным доверенным сертификатом и локально доступным доменом. Обычная LAN без этой подготовки использует HTTP; самоподписанный сертификат не выдаётся за решение без настройки гостей.

История ИИ изолирована по игроку и миссии. При отзыве доступа или выходе из миссии приватный контекст очищается. Источники и закрытые факты фильтруются до передачи модели. Проверка цитат сохранена; темы расследования требуют доступных дословных свидетельств. Свободный ответ модели может ошибаться: тематическая проверка не доказывает истинность каждого пересказа. Статус `ready` проверяет службу/наличие весов, а успешную генерацию подтверждает только настоящий ответ `mode: model`.

## Оставшиеся проверки

Установку коннектора попытались выполнить через `go run . --install-tunnel`: GitHub недоступен из sandbox (`lookup api.github.com: no such host`). Коннектор здесь не установлен, реальная HTTPS-ссылка не создана. Запуск на двух физических устройствах, внешний Cloudflare, реальные веса Ollama, браузерный внешний вид и аппаратный FPS не подтверждены. Windows/Linux только собраны перекрёстно.

После запуска в обычном терминале проверьте: два отдельных аккаунта → одна экспедиция → роли/готовность → общий чат → движение/открытие/проход/закрытие двери у обоих → ответ наставника с подписью «Локальная модель» → возврат в помещение без сброса состояния. На desktop проверьте зелёный ореол формы входа, читаемые подписи и отсутствие мерцания в движении. Эти проверки нельзя заменять результатами in-memory тестов.
