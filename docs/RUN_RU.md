# Запуск LastCrew FlightDeck

## На этом Mac

1. Остановите прежний сервер сочетанием **Ctrl+C** в его терминале.
2. Откройте терминал и выполните:

```sh
cd /Users/a1/Desktop/LastCrew_FlightDeck
./lastcrew
```

3. Откройте **http://localhost:8080**. Если игра была открыта до обновления, перезагрузите страницу: **Cmd+Shift+R**.
4. Создайте аккаунт или войдите → создайте экспедицию → выберите роль → **«Я готов» → «Начать миссию»**. Для одиночной игры выберите **«Управлять всеми системами»**.
5. Нажмите **«Исследовать»** и кликните по сцене.

Можно запускать двойным кликом по `Start.command`: он использует бинарник из `bin/` и клиент из `web/`. Go, npm и Python для готовой игры не нужны.

## Управление

| Действие | Клавиши |
|---|---|
| Ходить | WASD / стрелки |
| Смотреть | Мышь |
| Бежать | Shift |
| Дверь, предмет или разговор рядом | E |
| Положить контейнер | G |
| Освободить курсор | Esc |

Кнопки отсеков переключают обзор; до другого отсека игрок идёт пешком.

**Большой разговор:** откройте «Связь» и нажмите **⤢** в верхней части окна. Панель разворачивается до 760 px; повторное нажатие уменьшает её.

**Рабочий свет:** кнопка **«Свет включён / Включить свет»** рядом с переключением вида. Свет включён по умолчанию и доступен до ремонта реактора. Выбор сохраняется только в вашем браузере и не меняет ресурсы команды.

## Если всё ещё тормозит

- **Настройки → Разрешение 3D → Экономное**: меньше разрешение сцены, отключены динамические тени; интерфейс сохраняет чёткость.
- Если на сцене написано **«Совместимый режим»**, работает программный Canvas-рендер. Включите аппаратное ускорение в браузере и перезапустите браузер. Диагностика по кнопке **«МИР … / 30%»** показывает WebGL или Canvas и текущий FPS.
- Владелец экспедиции может уменьшить число фоновых NPC через **«Администратор → Вселенная»**, например до 16. Это общая настройка экспедиции.
- Чтобы проверить игру без нагрузки от локальной модели, остановите сервер и запустите:

```sh
OLLAMA_ENABLED=false ./lastcrew
```

Это отключает генерацию моделью в игре; справочный режим остаётся доступен. Если другая программа использует Ollama, эта команда её не останавливает.

## ИИ-наставники — по желанию

Для ответов моделью отдельно запустите установленную Ollama (приложение либо `ollama serve`). На хосте нужна модель `qwen3:4b-instruct-2507-q4_K_M`; её можно заранее загрузить командой `ollama pull qwen3:4b-instruct-2507-q4_K_M`. Загрузка требует интернета. Для гибридного поиска по статьям также используется `embeddinggemma`.

Запускайте игру обычной командой `./lastcrew`, затем откройте **«Связь → Наставник → Проверить ИИ»**. Подробности поиска и сети — [NETWORK_AND_AGENTS.md](NETWORK_AND_AGENTS.md).

## Другие компьютеры и запуск из исходников

| Система хоста | Команда / файл |
|---|---|
| macOS Apple Silicon | `Start.command` или `./lastcrew` |
| Windows x64 | `Start.bat` |
| Linux x64 | `bash Start.sh` |
| Из исходников, Go 1.23+ | `go run .` |

Запускайте из папки проекта. Сохраните рядом `world/`, `knowledge/`, `web/` и `bin/`; аккаунты и прогресс находятся в `data/`. Для первой сборки Go нужны зависимости в кеше либо доступ к сети. После изменения исходников пересоберите: `go build -o lastcrew .`.

Другу в той же локальной сети нужен только браузер: используйте адрес из кнопки **«Пригласить»**, отдельный аккаунт и код экспедиции. Для интернета есть `./lastcrew --share`; подготовка HTTPS описана в [сетевом гайде](NETWORK_AND_AGENTS.md).

Если порт 8080 занят, остановите старый процесс в его терминале или используйте другой порт:

```sh
HOST_ADDR=0.0.0.0:8081 ./lastcrew
```

Тогда адрес — http://localhost:8081. Остановка игры — **Ctrl+C**. Чтобы сохранить резервную копию, остановите сервер и скопируйте папку `data/`.
