# Проверка трёх документальных корпусов RAG

Дата: 31 октября 2026 года. Среда: Linux amd64, Go 1.23.12. Отчёт относится к обновлению трёх персонажей; прежний `TEST_REPORT.md` описывает исходную сборку.

Добавлено 60 документов и 163 чанка: Джанибеков — 20/88, Рязанский — 20/27, Крикалёв — 20/48. Все источники имеют URL, происхождение и тип текста. Готовые файлы прошли загрузчик Go и проверку повторной генерации Python.

Выполнено:

- `go test -mod=vendor ./...` — успешно, включая новые проверки реального корпуса, передачи контекста трёх персонажей в HTTP API модели, продолжения разговора и изоляции игроков.
- `go vet -mod=vendor ./...` — успешно.
- `go test -race -mod=vendor ./internal/npc ./internal/agents ./internal/server` — успешно.
- Проверка синтаксиса изменённых JS-модулей через Node — успешно.
- Новый тест с настоящим HTTP/WebSocket-сервером, регистрацией, `player.init` и тремя `agent.talk` — ответы всех персонажей прошли через тестовый Ollama API, содержат ссылки и принимаются контрактом `protocol.AgentReply`.
- Проверено, что карточка источника соответствует документу, реально указанному моделью, даже когда она цитирует второй результат поиска.
- Скомпилированный MCP-процесс: initialize/notifications/initialized, поиск и список источников всех трёх персонажей — успешно. Дополнительно проверены вопросы об утечках, корневой среде растений и международной подготовке.
- `mcp-tools -chunks knowledge -check`: 214 чанков загружено вместе с прежними корпусами; 196 видимы без открытия закрытых игровых фактов. Новые документальные чанки — 163.
- Бинарники `game-server.exe` и `mcp-tools.exe` заново собраны для Windows amd64. Linux-бинарники собраны и использованы для проверки MCP. Флаг `-buildvcs=false` позволяет собирать исходники из архива без Git-метаданных.
- Побайтово сохранены `knowledge/savinykh.jsonl`, `internal/agents/mentor.go`, оба исходных JSONL Mentor и `knowledge/scenario.jsonl`.

Уточнения:

- Реальная Ollama и веса модели в среде не были доступны. Проверялся совместимый локальный HTTP API; качество генерации конкретной модели и скорость на компьютере пользователя здесь не измерялись. Веса в поставку не включены.
- Windows-бинарники прошли кросс-компиляцию, запуск на Windows здесь не выполнялся. Отдельная визуальная проверка нового интерфейса в браузере не выполнялась; проверены JS-синтаксис и сериализация ответов по WebSocket.
- Повторный сбор получил 60 из 61 URL, включая транскрипцию книги. Один таймаут Zelenyikot покрыт ранее успешно полученным текстом того же дня. Сведения о полноте, OCR двух страниц одной презентации и расхождении биографии Рязанского описаны в `docs/crew-rag.md` и manifest.
- Проверка цитат подтверждает принадлежность ID найденным источникам; она не равнозначна проверке каждой свободной фразы модели. Новые корпуса используют имеющийся BM25, без эмбеддингов и дообучения.
