# Проверка объединённой сборки — 31 октября 2026

## Выполнено

- `CGO_ENABLED=0 go test -mod=vendor ./... -timeout 60s` — все пакеты прошли.
- `go vet -mod=vendor ./...` — без замечаний.
- Сборка Windows amd64: game-server.exe и mcp-tools.exe, без CGO.
- MCP `-check`: 51 загруженный чанк, 33 публично видимых, корпус корректен. `-export-tools`: 40 инструментов.
- Тесты адаптера: прогнозы совпадают с настоящими операциями текущего ScenarioEngine, чтение не меняет ресурсы; скрытые чанки закрыты; живая проекция обновляется и удаляет отключившегося игрока; исторический/игровой контекст не перепутан.
- Сохранённые серверные интеграционные тесты: авторизация до WebSocket, два клиента, синхронизация, переподключение, сохранение позиции, работа сокета во время диалога.

## Браузер Chrome

Автоматизация запустила готовый game-server.exe. WebGL отрисован, в сцене показан капитан у штурвала. Проверены регистрация и вход, четыре локальных персонажа с RAG и живым analysis, исторический ответ Савиных со ссылкой, продолжение темы, общая операция двух независимых браузерных клиентов, 390 px без горизонтального переполнения, переподключение и выход. Ошибок JavaScript нет, внешних сетевых запросов нет.

Пока игрок оставался подключён, отдельный mcp-tools.exe прошёл initialize/tools/list/tools/call по stdio, прочитал тот же остаток энергии после операции и вычислил прогноз. Это проверка процесса MCP, а не только прямого вызова Go-функции.

## Что не проверялось

Физическая LAN из двух ноутбуков, конкретный внешний MCP-клиент и реальные веса Ollama. Контракт Ollama, отказ модели и ограничения инструментов покрываются локальными тестовыми HTTP-серверами. Браузерные прогоны выполнены с выключенной LLM. SQLite, AOI/10% и WebXR не входят в завершённую интеграцию.
