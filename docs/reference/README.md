# Исходные донорские материалы

Здесь сохранены scenario-donor.jsonl, scenario-manifest-donor.json и build_scenario_corpus.py из chronograd-agents-mcp.zip. Это материалы для сравнения и развития отдельной донорской библиотеки, не активный корпус объединённой игры.

В оригинале капитаном был Джанибеков, инженером Савиных; по указанию пользователя в активной сборке роли поменяны. Исходный импортёр воспроизводит первоначальный документ и не сохраняет сделанные адаптации. Не направляйте его вывод поверх knowledge/ без повторного согласования ролей и численных правил. Список восьми адаптированных чанков находится в knowledge/scenario-manifest.json.
